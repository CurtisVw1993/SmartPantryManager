# Smart Pantry Manager

Smart Pantry Manager is an Android application developed in Java using Android Studio for the Mobile App Development 700 assignment.

## Features

- Add ingredients
- Edit ingredients
- Delete ingredients
- Persistent Room Database storage
- Recipe recommendations
- Recipe matching based on available ingredients
- Recipe detail view
- Settings screen
- Clear pantry functionality
- About page

## Technologies Used

- Java
- Android Studio
- Room Database
- RecyclerView
- Android Activities
- SQLite
